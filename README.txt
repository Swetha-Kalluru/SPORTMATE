SPORTMATE — Installable Web App (PWA)

WHAT THIS IS
This package turns the SPORTMATE browser prototype into an installable Progressive Web App (PWA).
It can be added to an Android home screen after it is hosted on an HTTPS website.

HOW TO TEST
1. Extract this ZIP.
2. Host the folder on an HTTPS static host (for example, GitHub Pages or Netlify).
3. Open the hosted website in Chrome on Android.
4. Open Chrome's menu and choose "Install app" or "Add to Home screen" (wording may vary).

IMPORTANT LIMITATIONS
- This is an installable web app, not a native Android APK.
- Profile and application demo data is saved in the same browser on the same device.
- There is no shared online database, real account authentication, verified listings, or real messaging yet.
- The service worker caches the app shell for repeat/offline opening; data sync is not provided.
